# DevCompanion
DevCompanion serves as a backend API platform that enables developers to:

Register and manage user profiles with specializations and technologies
Create and respond to help requests and collaboration invitations
Form and manage development teams
Receive real-time notifications via Firebase Cloud Messaging
Communicate through automated email notifications

Core Business Features

User Management System:
User registration with email confirmation
JWT-based authentication and authorization
Profile management with specializations and technology stacks
Role-based access control
FCM token management for push notifications

Request Management System:
Help request creation and broadcasting
Team join request functionality
Request acceptance and rejection workflows
Team-based request filtering
Automated notification system
Team Management System:

Team creation with admin assignment
Member invitation and management
Team-based collaboration features
Member role administration
